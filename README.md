# REPARIA • Asistente de Reparación Doméstica con IA

Aplicación Android moderna desarrollada con **Jetpack Compose** y Kotlin para el diagnóstico guiado y la resolución de averías en el hogar.

## Características Principales
- **Diagnóstico en 3 pasos:** Flujo rápido con análisis visual y acústico.
- **Manejo de Errores en 3 Partes:** Qué pasó, por qué y acción correctiva inmediata.
- **Banner de Voz y Tono Dinámico:** Adaptación de tono imperativo para riesgos eléctricos/gas o motivador para tareas seguras.
- **Guía de Reparación Interactiva:** Checklist paso a paso con métrica de tiempo y herramientas requeridas.

## Arquitectura
- **Jetpack Compose + Material 3**
- **MVVM** con StateFlow y ViewModel
- **Corrutinas** para simulación de visión computacional

- **Kotlin 2.0 & AGP 8.7**
